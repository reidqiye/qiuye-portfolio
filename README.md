# Qiuye Zhu · Portfolio

A hand-drawn bar with three windows — **About**, **Works** and **Contact**. Hover a window to switch on its lamp; click it and the drink pours down into the page below.

- `index.html` — page structure
- `style.css` — layout, colours and animations
- `main.js` — lighting, the pour transition and the works menu (project data lives at the top of this file)
- `assets/` — illustration layers (drawn in Procreate) and project covers

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
